# ---------------------------------------------------------------- Command line: help (--help)
arg.beschreibung = local transcription (faster-whisper)
arg.audio = audio, video or DVD inputs (file, .iso, VIDEO_TS folder)
arg.profil = profile name or profile file (.json)
arg.modell = short name, name or folder of the model (default: profile)
arg.sprache = language of the recording: de, en, … or auto (default: profile)
arg.begriffe = terms, comma-separated
arg.begriffe_datei = text file with terms (default: profile)
arg.kontext = sentence about the topic as a recognition hint (default: profile)
arg.ausgabe = output folder (default: profile, otherwise next to the audio file)
arg.test = only the first n seconds (sample run)
arg.woerter = word timestamps (more precise subtitles, JSON with word times)
arg.raster = time grid in seconds, e.g. 0.5 1 5 (turns on --woerter)
arg.spur = audio track (0 = first); overview with --spuren
arg.spuren = only list audio tracks, do not transcribe
arg.titel = DVD title set (VTS_xx); default: largest
arg.nur_datei = for VTS_xx_n.VOB only this file instead of the whole title
arg.ffmpeg = path to ffmpeg.exe (default: profile)
arg.threads = CPU cores (default: profile)
arg.compute = compute type: int8, int8_float32, float32 (default: profile)
arg.beam = beam size (default: profile, otherwise 5)
arg.absatz = new paragraph in .txt after this speech pause in s (default: profile, otherwise 2)
arg.kein_protokoll = do not write a log file
arg.pruefen = only check the setup of the profile
arg.ui = language of messages and log, e.g. de or en (default: as in the interface)
arg.sprachen_pruefen = check language files for missing entries
